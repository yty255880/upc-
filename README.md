# 中石大学生助手 · 中国石油大学（华东）校园导览

![校徽](images/emblem.png)

> 一个面向新生的多校区校园导览（Web / PWA / Android App）。
> 古镇口西区、古镇口东区、唐岛湾校区、东营科教园区，一处地图轻松切换。

## ✨ 功能特性

- 🗺️ **四校区地图**：古镇口西区（主）、古镇口东区、唐岛湾校区、东营科教园区一键切换；Leaflet 卫星/街道图层 + 高德官方矢量地图（JS API）
- 📍 **55+ 地标**：教室、图书馆、餐厅、宿舍、体育馆、医院、雕塑广场等，点击图钉看图文介绍与实景照片
- 🔍 **地点查找与搜索**：全站联想搜索 + 分类筛选 + 快速直达
- 🧭 **校内导航**：选起点/终点自动规划，多路线、按距离最短优先
- 🎓 **学院院系**：各学院简介 + 所在校区，支持本科生/研究生板块切换
- 📚 **选课与我的课程**：选课中心 + 自主添加课程，真实课表视图（周一~周日 × 节次）
- 👤 **个人中心**：昵称、头像上传、课程统计、校训「惟真惟实」与校风、暗色/浅色主题
- 🖼️ **实景相册**：校区高清照片灯箱浏览（古镇口/唐岛湾/东区筛选）
- 📱 **手机形态**：PWA 可安装到主屏幕全屏使用；Android 可安装「中石大学生助手」APK（WebView 离线可用、联网自动同步最新内容）
- 📋 **更新日志**：页面内置折叠式版本历史；公众号/学生会/官网二维码 + 一键跳转官网

## 🧩 技术栈

- 原生 HTML + CSS + JavaScript 单文件应用（无构建步骤，改完即用）
- [Leaflet 1.9.4](https://leafletjs.com/)（本地化，离线可用）+ Esri / 高德 / OSM 瓦片
- 高德开放平台 JS API 2.0（可在地图右上角「⚙️ 设置」更换自己的 Key）
- PWA：`manifest.webmanifest` + `sw.js`（网络优先、离线缓存）
- Android：原生 `WebView` 工程打包（`com.zsd.student.assistant`），同签名可覆盖升级

## 🗂️ 目录结构

```
├── 中国石油大学华东校园导览.html   # 主程序（单文件 App：样式/交互/数据全在其中）
├── index.html                     # 入口（跳转到主程序）
├── manifest.webmanifest           # PWA 清单
├── sw.js                          # Service Worker（离线缓存 + 网络优先）

├── lib/                           # Leaflet 本地库
├── download/                      # Android APK 与 version.json（App 更新检测）
├── docs/                          # README 用截图
├── README.md
├── LICENSE
└── CHANGELOG.md
```

## 🚀 本地运行

- **最简**：直接双击 `中国石油大学华东校园导览.html` 用浏览器打开（Leaflet 已本地化；瓦片与高德 API 需联网）
- **局域网 / 手机预览**：
  ```bash
  python -m http.server 8000 --directory .
  ```
  手机访问 `http://<电脑IP>:8000/`

## 📲 手机安装

1. **网页版（推荐先试）**：浏览器打开在线地址 → 菜单「添加到主屏幕 / 安装应用」，全屏像 App 一样用；
2. **Android App**：在网站「📲 手机 App 与网页版」板块点「下载 APK」，或直接下载 `download/中石大学生助手-v1.18.0.apk` 安装（Android 7.0+，同签名可覆盖升级，数据保留）；
3. **iPhone**：Safari 打开 → 分享 → 「添加到主屏幕」。

## 🛠️ 二次开发 / 发布

- 主体是一个单文件应用，直接编辑根目录 HTML 中的结构/CSS/JS 即可；
- 发布到 **GitHub Pages**：
  ```bash
  git add -A
  git commit -m "update"
  git push origin master   # Pages 会自动更新 https://<用户名>.github.io/<仓库>/
  ```
- 修改内容后请同步递增 `site-version.json`（网页自动更新机制会据此让旧页面刷新到最新，无需用户清缓存）；
- 安卓 APK 的 WebView 工程与签名密钥保存在本地工作区（**密钥不入库**），需要新包时在本地构建并上传至 `download/`。
